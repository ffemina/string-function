# string-function
A beginner-friendly SQL project using MySQL to manage and analyze student data. Covers SELECT, WHERE, filtering, string functions, date functions, aggregate functions, GROUP BY, HAVING, and ORDER BY.
SQL String and Date Functions – College Database

Project Overview

This project focuses on practising String Functions and Date Functions in MySQL using the college_db database and the students table.

The exercises demonstrate how to manipulate text, extract specific characters, format dates, and perform date calculations using SQL built-in functions.

Topics Covered

1. String Functions

UPPER() – Converts first names into capital letters.

LOWER() – Converts last names into small letters.

CONCAT() – Combines first name and last name to display full names.

LENGTH() – Counts the number of characters in a name.

SUBSTRING() – Extracts specific characters from a string.

LEFT() – Extracts the first few characters from a string.

TRIM() – Removes extra spaces from the beginning and end of text.

2. Date Functions

YEAR() – Extracts the year from a date.

MONTH() – Extracts the month from a date.

DATE_FORMAT() – Displays dates in different formats.

DATEDIFF() – Calculates the difference between two dates.
